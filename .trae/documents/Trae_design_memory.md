# Trae Design Memory — IJX_App

> 本文件记录 IJX_App（吉祥航空企业 App H5 前端复刻项目）的设计参考与核心约定，供 Agent 在后续迭代中保持设计一致性。

## 1. Design Overview
本项目是吉祥航空企业内部 App 的 H5 前端复刻版，基于现有 App 截图进行 1:1 还原。主用户：梁吉力（"我的"页面显示昵称梁劼）。复用 IJX_Platform 的人名与头像数据，保持吉祥航空品牌视觉（粉/紫色调 + 飞机 + 花卉元素）。

## 2. Page Features（页面功能）

### 2.1 首页（Home）
- **Header**：上海市定位 + 快捷服务入口搜索框 + 二维码图标 + 铃铛(10)
- **Stats Banner**：4 宫格数字卡（未读公文 50、待办流程 11、今日日程 2、我的课考 99+）+ "心有吉祥如意必至"标题 + 花卉插画装饰
- **Quick Apps**：会议室、通讯录、流程中心、员工活动、公司值班、全部（6 宫格）
- **Report Banner**：2025 可持续发展报告（点击查看完整报告）
- **Docs Tabs**：公司文件、会议纪要、通知公告、邮、更多（5 胶囊 Tab）+ 文档列表（标题 + 发文号）
- **Welfare Center**：工金福利专区、生日福利（2 卡片）
- **Mall**：吉祥航空 IP 熊猫公仔 ¥55.00 × 3（横向滚动）
- **Recommend**：休闲度假旅游产品 2×2 网格（价格起价）

### 2.2 日程（Schedule）
- **Tabs**：日程/任务双 Tab（下划线指示）
- **Task Subtabs**：待处理 0 / 已处理 7（粉色/灰色胶囊）
- **Calendar**：2026 年 7 月历、农历 + 节日标记（建党节、建军节、小暑、大暑）、选中日期实心粉圆、日程点标记
- **Timeline**：时间段块（13:15-14:00、14:30-15:30）、圆点指示、标题

### 2.3 工作台（Workspace）
- **Search**：顶部搜索框（"请输入您要搜索的内容"）
- **My Apps**：会议室、通讯录、流程中心、员工活动室、公司值班（5 个 + 编辑按钮）
- **Sections**：推荐应用（3）/ 综合服务（15）/ 文档中心（4）/ 员工服务（12）/ 数据服务（1）/ 信息查询（1）

### 2.4 消息（Message）
- **Message List**：系统/同事/群聊消息卡片、未读标记、时间戳

### 2.5 我的（Profile）
- **Header**：飞机背景渐变 + 退出/设置图标
- **名片卡**：64px 圆形头像 + 姓名（梁劼）+ 性别图标 + 名片 tag + 职位（产品经理）+ 部门（信息管理部-管理支撑产品处）+ 箭头
- **入职提示**：2023-07-03 第 1101 天（黄色背景条）
- **快捷四宫**：我的薪酬、我要打卡、我的福利、我的钱包
- **WiFi 广告**：飞机上免费上网提示
- **吉食GO**：钱包余额 ¥22.85 + 付款码按钮
- **菜单组**：我的邮箱 / 梧桐云学堂(16) / 我的 IT 资源 / 帮助与反馈 / 账户安全中心 / 退出账号

## 3. Design Style（设计风格 — iOS 26）

### 3.1 配色系统
| 用途 | 色值 | 示例 |
|------|------|------|
| 主题粉 | `#ff8aa0` / `#ff6b9d` / `#ff3b6b` | Banner、徽章、性别图标、Tab 高亮 |
| 紫色渐变 | `#c4a0e8` → `#a888d4` | 首页 Hero 区背景 |
| 飞机蓝渐变 | `#c4e0e8` → `#a8d4dc` | "我的"页面 Header |
| 暖米色 | `#fdf4e3` / `#fdf0d4` | 入职提示、WiFi 广告、吉食GO |
| 卡片白 | `#fff` | 内容卡片 |
| 背景灰 | `#f5f5f5` | 页面背景 |
| 主文字 | `#333` | 标题、正文 |
| 次要文字 | `#999` | 辅助信息、部门 |
| 占位灰 | `#ccc` | 分割线、箭头 |

### 3.2 圆角与阴影
- **卡片**：`8-12px`
- **按钮**：`20px`（胶囊）
- **头像**：`50%`（圆形）
- **阴影**：`0 1px 4px rgba(0,0,0,0.04)`（轻柔卡片阴影）

### 3.3 字体规范
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Tab 标题 | `20px` | 600 | 日程/任务、首页/日程等 |
| 区块标题 | `16px` | 600 | 我的工作台、推荐应用等 |
| 正文 | `13-14px` | 400 | 文档标题、菜单文字 |
| 辅助文字 | `12px` | 400 | 发文号、部门、价格 |
| 数字徽章 | `11-12px` | 600 | 未读数量、待办计数 |

### 3.4 图标规范
- **库**：FontAwesome 6（fas/far）
- **主色**：`#ff8aa0`（工作台应用）或 `#555`（菜单图标）
- **尺寸**：28px（应用图标）、22px（菜单图标）

### 3.5 布局规范
- **视口宽度**：iPhone 标准 375px / 390px
- **安全区**：底部 TabBar `70px`
- **栅格**：4 列（快捷应用/工作台）、2 列（商城商品/旅游推荐）
- **触控目标**：≥ 44px

## 5. Design Principles（设计原则）
1. **品牌一致**：吉祥航空主色（粉/紫/飞机蓝）贯穿所有页面
2. **iOS 26 视觉**：圆角 12px、胶囊按钮、轻阴影、系统字体
3. **移动优先**：以 375-390px 视口设计，触控目标 ≥ 44px
4. **占位友好**：banner/商品/旅游图用 `text_to_image` 占位，避免空图
5. **数据复用**：人名/头像从 IJX_Platform people.ts 引入
6. **渐进增强**：先还原视觉，再补交互，最后接后端
